# Binsen（便箋）

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md) | **日本語** | [Español](README.es.md)

iPhone でひとことメモすると、数秒後、Mac のデスクトップにある純正の「スティッキーズ」(Stickies) に、そっと 1 枚増えています。

https://github.com/user-attachments/assets/12b98983-d6f9-4837-83bc-dde8d83b0335

**Binsen** は日本語の「便箋（びんせん）」から名付けました。外出先でふと浮かんだアイデア、ちょっとした ToDo、メモの切れ端——自分宛てにメッセージを送ったり、重たいノートアプリを開いたりする必要はもうありません。Mac の前に戻れば、もうデスクトップに貼ってあります。

```text
iPhone のショートカット「Binsen」
  └─ .txt として保存 ──▶ iCloud Drive/ショートカット/Binsen
                        └─ Mac の常駐プロセスが新しいファイルを検知
                              ├─ 「スティッキーズ」に新しいメモを静かに作成して書き込み
                              └─ 元のファイルを Binsen/已处理 にアーカイブ
```

## 特長

* **純正アプリそのもの**：macOS に標準搭載の「スティッキーズ」に直接書き込みます。サードパーティ製の、それらしく見せたフローティングウインドウではありません。
* **作業を邪魔しない**：すべてバックグラウンドで処理し、使用中のウインドウのフォーカスを奪いません。Mac で入力している最中でも中断されません。「スティッキーズ」が起動していない場合は、起動時に自動で作られる空白のメモをそのまま使うので、余分な空白メモは残りません。
* **クリップボードに触れない**：システムのクリップボードを一切読み書きしません。
* **外部依存ゼロ**：サーバー不要、アカウント登録不要、ネットワークポートも開きません。iCloud Drive の同期だけで動きます。
* **シンプルで透明**：コアロジックは Swift ファイル 1 つだけ。サードパーティの依存はなく、すぐに読み切れます。

## 動作環境

* macOS 13 以降
* Xcode またはコマンドラインツール（`xcode-select --install` でインストールできます）
* Mac と iPhone で同じ Apple アカウントにサインインし、**iCloud Drive** をオンにしていること

## はじめかた

### 1. Mac にインストール

```bash
git clone https://github.com/Qinov5/Binsen.git
cd Binsen
zsh install.sh
```

インストールスクリプトが次の処理を自動で行います：**ビルド → `~/Applications/Binsen.app` にインストール → iCloud に受信フォルダを作成 → ログイン時の自動起動を登録 → セルフチェック用のメッセージを投入**。

デスクトップのスティッキーズに **「Binsen 已接通 ✅」**（「Binsen 接続完了」の意味）と表示されれば、インストールは成功です。

> **アップデート**：プロジェクトのフォルダで `git pull && zsh install.sh` を実行すると上書き更新できます。
>
> **署名について**：スクリプトはキーチェーン内の `Apple Development` 証明書を優先して署名に使います（初回に `codesign` がキーチェーンにアクセスしてよいか聞かれたら「常に許可」を選んでください）。これにより、アップデート後もシステムの許可が保持されます。開発者証明書がない場合はアドホック署名になり、アップデートのたびに許可し直す必要があります。
>
> **表示言語**：インストールスクリプトとログのメッセージは、現在は簡体字中国語のみです。

### 2. 操作の許可を与える（強く推奨）

初回のセルフチェック時に、システムが操作の許可を求めてきます。Binsen に許可するのは **「スティッキーズ」** の 1 つだけで十分です。許可すると、メニュー経由で静かにメモを作成でき、フォーカスを奪わず、起動直後の余分な空白メモも出なくなります。

| macOS のバージョン | 許可の方法 |
| :--- | :--- |
| **macOS 27.3 以降** | ダイアログで **Choose Apps** をクリックし、「スティッキーズ」だけを追加して、右側を **At Any Time** に変更します（*Ask First* を選ぶと毎回確認ダイアログが表示されます）。あとから `システム設定 → プライバシーとセキュリティ → System & App Protection Override` で変更することもできます。 |
| **それ以前** | `システム設定 → プライバシーとセキュリティ → アクセシビリティ`（macOS 27 の初期バージョンでは *Device Control and Data Access*）で **Binsen** をオンにします。 |

*注：許可しなくても使えます。その場合はシステムサービス（Make Sticky）でメモを作成する方式に自動で切り替わりますが、作成時に「スティッキーズ」が最前面に来るほか、スティッキーズが起動していなかったときに空白のメモが 1 枚余分に残ることがあります。*

### 3. iPhone にショートカットを追加

iPhone で下のリンクを開き、用意されたショートカットを追加します：

👉 **[ショートカット「Binsen」を追加](https://www.icloud.com/shortcuts/22b6bb3e26b046278a8ee42ee9dd0edd)**

やることは 2 つだけ：テキストの入力欄を表示 → 内容を `iCloud Drive › ショートカット › Binsen` に保存。追加したら一度実行して、ひとこと書いてみてください。

💡 **ちょっとしたコツ**：iPhone に「アクションボタン」がある場合は、`設定 → アクションボタン → ショートカット` で **Binsen** を選ぶと、サイドボタンを押すだけでメモを貼れるようになります。ロック画面のウィジェットや「背面タップ」から起動するのもおすすめです。

<details>
<summary>リンクを使わずに手動で作成する</summary>

1. 「ショートカット」App を開き、右上の **＋** をタップして、名前を `Binsen` にします。
2. アクション **入力を要求** を追加し、入力の種類を「テキスト」にします。
3. アクション **ファイルを保存** を追加します：
   * 保存する内容は「指定入力」
   * 「保存先を尋ねる」を **オフ**
   * サブパスに `/Binsen/` と入力

*（Mac のショートカット App で作成しても、iCloud 経由で iPhone に自動で同期されます。）*
</details>

## 詳細設定

`defaults` コマンドで既定の動作を変更できます：

```bash
# メモ作成後も「スティッキーズ」を最前面のままにする（既定では元のウインドウにフォーカスを戻します）
defaults write io.github.qinov5.binsen RestoreFocus -bool false

# 監視する受信フォルダを変更する
defaults write io.github.qinov5.binsen InboxPath "~/任意のフォルダ"

# 設定を変更したら、バックグラウンドサービスを再起動して反映する
launchctl kickstart -k gui/$(id -u)/io.github.qinov5.binsen
```

## トラブルシューティング

| 症状 | 対処 |
| :--- | :--- |
| なかなかメモが現れない | ログを確認：`tail -20 ~/Library/Logs/Binsen.log` |
| iPhone では保存できたのに、Mac の受信フォルダが空 | たいていは iCloud の同期待ちか、Mac がスリープ中です。`Finder › iCloud Drive › ショートカット › Binsen` にファイルが届いているか確認してください |
| ログに `没有控制「便笺」的权限`（スティッキーズを操作する許可がない）と出る | 上の「操作の許可を与える」を参照して許可してください |
| メモ作成後、フォーカスが元のウインドウに戻らない | まず許可の設定を確認してください。それでも起きる場合は、ログの `焦点没能还给…` で始まる行を Issues に貼ってください |
| バックグラウンドサービスが動いているか確認したい | `launchctl print gui/$(id -u)/io.github.qinov5.binsen \| grep state` を実行 |

## アンインストール

```bash
zsh uninstall.sh
```

アンインストールで削除されるのは、バックグラウンドアプリと自動起動の設定だけです。**iCloud の受信フォルダと、デスクトップにある既存のメモはすべてそのまま残ります。**

## しくみとディレクトリ構成

* **軽量な常駐**：`Binsen.app` は Dock にアイコンを出さないバックグラウンドアプリで、ログイン時に `LaunchAgent` から起動され、2 秒ごとに受信フォルダを確認します。
* **クラウド上のファイルをオンデマンドで取得**：iPhone から同期されたばかりの `.txt` は、Mac 上ではまだダウンロードされていないプレースホルダのことがあります。`setiopolicy_np` でオンデマンドダウンロードを有効にし、準備ができていないファイルには `brctl download` でダウンロードを促します。
* **気づかれない書き込み**：テキストを読み込んだら、アクセシビリティ API でスティッキーズのメニュー「新規メモ」（`⌘N`）を直接実行して内容を書き込みます。スティッキーズのウインドウはアクティブにしません。スティッキーズが起動していない場合はバックグラウンドで静かに起動し、最初の空白メモに直接書き込みます。許可がない場合は `NSPerformService("Make Sticky", …)` に切り替え、できる限りフォーカスを元に戻します。

```text
Sources/main.swift   監視と書き込みのコアロジック（1 ファイル、依存なし）
Info.plist           UI を持たないバックグラウンド App の設定
Icon/                App アイコン（AppIcon.svg が元データ。インストール時に macOS のバージョンに合わせて .icns を選択）
install.sh           ビルド、署名、インストール、自動起動、エンドツーエンドのセルフチェック（繰り返し実行して更新可能）
uninstall.sh         App と自動起動サービスを削除
```
