# Binsen（便箋）

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md) | **日本語** | [Español](README.es.md)

iPhone でひとことメモすると、数秒後、Mac のデスクトップにある純正の「スティッキーズ」(Stickies) に、そっと 1 枚増えています。

https://github.com/user-attachments/assets/12b98983-d6f9-4837-83bc-dde8d83b0335

**Binsen** は日本語の「便箋（びんせん）」から名付けました。外出先でふと浮かんだアイデア、ちょっとした ToDo、メモの切れ端——自分宛てにメッセージを送ったり、重たいノートアプリを開いたりする必要はもうありません。Mac の前に戻れば、もうデスクトップに貼ってあります。

```text
iPhone のショートカット「Binsen」
  ├─ おすすめ：リマインダーのリスト「Binsen」に追加 ──▶ iCloud、数秒で同期
  └─ 旧方式：.txt として保存 ──▶ iCloud Drive/ショートカット/Binsen
                        └─ Mac に常駐する Binsen が新しい内容を受け取る
                              ├─ 「スティッキーズ」に新しいメモを静かに作成して書き込み
                              └─ リマインダーは完了にし、ファイルは Binsen/已处理 にアーカイブ
```

## 特長

* **純正アプリそのもの**：macOS に標準搭載の「スティッキーズ」に直接書き込みます。サードパーティ製の、それらしく見せたフローティングウインドウではありません。
* **作業を邪魔しない**：すべてバックグラウンドで処理し、使用中のウインドウのフォーカスを奪いません。Mac で入力している最中でも中断されません。「スティッキーズ」が起動していない場合は、起動時に自動で作られる空白のメモをそのまま使うので、余分な空白メモは残りません。
* **クリップボードに触れない**：システムのクリップボードを一切読み書きしません。
* **外部依存ゼロ**：サーバー不要、アカウント登録不要、ネットワークポートも開きません。あなた自身の iCloud（リマインダーまたは iCloud Drive）の同期だけで動きます。
* **シンプルで透明**：コアロジックは Swift ファイル 1 つだけ。サードパーティの依存はなく、すぐに読み切れます。

## 動作環境

* macOS 13 以降
* Xcode またはコマンドラインツール（`xcode-select --install` でインストールできます）
* Mac と iPhone で同じ Apple アカウントにサインインし、iCloud の **リマインダー** をオンにしていること（旧方式のファイル保存を使う場合は **iCloud Drive** も必要）

## はじめかた

### 1. Mac にインストール

```bash
git clone https://github.com/Qinov5/Binsen.git
cd Binsen
zsh install.sh
```

インストールスクリプトが次の処理を自動で行います：**ビルド → `~/Applications/Binsen.app` にインストール → iCloud に受信フォルダを作成 → ログイン時の自動起動を登録 → iCloud Drive 経由とリマインダー経由をそれぞれセルフチェック**。

デスクトップのスティッキーズに **「Binsen 已接通 ✅」**（「Binsen 接続完了」）と **「Binsen 提醒事项通道已接通 ✅」**（「リマインダー経由も接続完了」）が表示されれば、インストールは成功です。

> **アップデート**：プロジェクトのフォルダで `git pull && zsh install.sh` を実行すると上書き更新できます。
>
> **署名について**：スクリプトはキーチェーン内の `Apple Development` 証明書を優先して署名に使います（初回に `codesign` がキーチェーンにアクセスしてよいか聞かれたら「常に許可」を選んでください）。これにより、アップデート後もシステムの許可が保持されます。開発者証明書がない場合はアドホック署名になり、アップデートのたびに許可し直す必要があります。
>
> **表示言語**：インストールスクリプトとログのメッセージは、現在は簡体字中国語のみです。

### 2. 操作の許可を与える（強く推奨）

初回のセルフチェック時に、システムが操作の許可を求めてきます。Binsen に許可するのは **「スティッキーズ」** の 1 つだけで十分です。許可すると、メニュー経由で静かにメモを作成でき、フォーカスを奪わず、起動直後の余分な空白メモも出なくなります。

| macOS のバージョン | 許可の方法 |
| :--- | :--- |
| **macOS 27.3 以降** | ダイアログで **Choose Apps** をクリックし、「スティッキーズ」だけを追加して、右側を **At Any Time** に変更します（*Ask First* を選ぶと毎回確認ダイアログが表示されます）。あとから `システム設定 → プライバシーとセキュリティ → System & App Protection Override` で変更することもできます。 |
| **それ以前** | `システム設定 → プライバシーとセキュリティ → アクセシビリティ`（macOS 27 の初期バージョンでは *Device Control and Data Access*）で **Binsen** をオンにします。 |

*注：許可しなくても使えます。その場合はシステムサービス（Make Sticky）でメモを作成する方式に自動で切り替わりますが、作成時に「スティッキーズ」が最前面に来るほか、スティッキーズが起動していなかったときに空白のメモが 1 枚余分に残ることがあります。*

**リマインダーへのアクセス**：インストール中に「リマインダー」へのアクセスを求めるダイアログが表示されるので、「許可」をクリックしてください。Binsen が読み書きするのは「Binsen」リストだけで（なければ iCloud に自動で作成します）、メモに貼り付けたリマインダーは完了にします。許可し忘れた場合は `システム設定 → プライバシーとセキュリティ → リマインダー` で Binsen をオンにしてから、もう一度 `zsh install.sh` を実行してください。

### 3. iPhone にショートカットを追加

おすすめは「リマインダー」版です。リマインダーはすぐに同期されるので、iPhone で送ってから Mac に貼られるまで、実測で約 10 秒です。

👉 **[ショートカット「Binsen」を追加](https://www.icloud.com/shortcuts/54ba2387d2b54ceebe1437aef3b34d47)**

やることは 2 つだけ：テキストの入力欄を表示 → 内容をリマインダーの「Binsen」リストに追加。追加したら一度開いて、リストが「Binsen」になっているか確認してください。違っていたら選び直せば大丈夫です（Mac に Binsen をインストールすると、このリストが自動で現れます）。

💡 **ちょっとしたコツ**：iPhone に「アクションボタン」がある場合は、`設定 → アクションボタン → ショートカット` で **Binsen** を選ぶと、サイドボタンを押すだけでメモを貼れるようになります。ロック画面のウィジェットや「背面タップ」から起動するのもおすすめです。

<details>
<summary>リンクを使わずに手動で作成する</summary>

1. 「ショートカット」App を開き、右上の **＋** をタップして、名前を `Binsen` にします。
2. アクション **入力を要求** を追加し、入力の種類を「テキスト」にします。
3. アクション **新規リマインダーを追加** を追加し、リマインダーの欄を「指定入力」（たいてい自動で入ります）、リストを **Binsen** にします（まだ表示されない場合は「リマインダー」App を一度開いて同期を待ってください）。

*（Mac のショートカット App で作成しても、iCloud 経由で iPhone に自動で同期されます。）*
</details>

<details>
<summary>旧方式：iCloud Drive にファイルとして保存（大きく遅れることがあります）</summary>

👉 [旧方式のショートカットを追加](https://www.icloud.com/shortcuts/22b6bb3e26b046278a8ee42ee9dd0edd)

手動で作る場合：**入力を要求**（テキスト）→ **ファイルを保存**（保存する内容は「指定入力」、「保存先を尋ねる」をオフ、サブパスは `/Binsen/`）。

> 注意：ショートカットが保存したファイルを、iPhone はすぐには iCloud にアップロードしないことが多く、「ファイル」App を開いたときに初めてアップロードが始まる場合があります。そのため数分〜数時間遅れることがあります。Mac 側は引き続きこのフォルダも監視しているので、旧方式のショートカットもそのまま使えます。
</details>

## 詳細設定

`defaults` コマンドで既定の動作を変更できます：

```bash
# メモ作成後も「スティッキーズ」を最前面のままにする（既定では元のウインドウにフォーカスを戻します）
defaults write io.github.qinov5.binsen RestoreFocus -bool false

# 監視する受信フォルダを変更する
defaults write io.github.qinov5.binsen InboxPath "~/任意のフォルダ"

# リマインダー経由で監視するリストを変更する（既定は Binsen。なければ自動で作成）
defaults write io.github.qinov5.binsen RemindersList "任意のリスト"

# リマインダー経由をオフにして、iCloud Drive のファイルだけを使う
defaults write io.github.qinov5.binsen UseReminders -bool false

# 設定を変更したら、バックグラウンドサービスを再起動して反映する
launchctl kickstart -k gui/$(id -u)/io.github.qinov5.binsen
```

## トラブルシューティング

| 症状 | 対処 |
| :--- | :--- |
| なかなかメモが現れない | ログを確認：`tail -20 ~/Library/Logs/Binsen.log` |
| メモが届くまでに時間がかかる | ログの `收到：` で始まる行を確認してください。iCloud がこの Mac に届けるまでにかかった時間と、その間 Mac がスリープしていた時間が記録されます。`收到` から `已贴到便笺` まではふつう 1〜2 秒なので、遅れはほぼ iCloud 側で起きています |
| Mac を閉じている間やスリープ中に送ったメモが出てこない | スリープ中の Mac ではメモを作成できません。スリープ解除後に iCloud の同期が追いつき、たいてい数十秒以内に自動で貼り付けられます |
| 旧方式（ファイルを保存）のショートカットだと、「ファイル」App を開くまで届かない | ショートカットが保存したファイルを、iPhone はすぐにはアップロードしません。上の「リマインダー」版のショートカットに切り替えてください |
| Mac が起きていて iPhone からも送信済みなのに、数分かかる | iCloud のプッシュ通知がプロキシや VPN に妨げられ、更新の通知が Mac に届いていない可能性が高いです。Shadowrocket や Clash などでシステムプロキシを設定している場合は、`*.push.apple.com` と `17.0.0.0/8` をプロキシをスキップするリストに追加してください |
| ログに `没有控制「便笺」的权限`（スティッキーズを操作する許可がない）と出る | 上の「操作の許可を与える」を参照して許可してください |
| ログに `提醒事项：没有访问权限`（リマインダーへのアクセス許可がない）と出る | `システム設定 → プライバシーとセキュリティ → リマインダー` で Binsen をオンにし、`launchctl kickstart -k gui/$(id -u)/io.github.qinov5.binsen` を実行してください |
| メモ作成後、フォーカスが元のウインドウに戻らない | まず許可の設定を確認してください。それでも起きる場合は、ログの `焦点没能还给…` で始まる行を Issues に貼ってください |
| バックグラウンドサービスが動いているか確認したい | `launchctl print gui/$(id -u)/io.github.qinov5.binsen \| grep state` を実行 |

## アンインストール

```bash
zsh uninstall.sh
```

アンインストールで削除されるのは、バックグラウンドアプリと自動起動の設定だけです。**iCloud の受信フォルダ、リマインダーの「Binsen」リスト、デスクトップにある既存のメモはすべてそのまま残ります。**

## しくみとディレクトリ構成

* **軽量な常駐**：`Binsen.app` は Dock にアイコンを出さないバックグラウンドアプリで、ログイン時に `LaunchAgent` から起動されます。FSEvents で受信フォルダを監視してファイルが届いた時点で処理し、念のため 2 秒ごとの確認も行います。作成に失敗したときは 2、4、8…秒の間隔で、貼り付けられるまで自動で再試行します。
* **リマインダー経由**：EventKit で「Binsen」リストの変化を監視し（さらに 1 分ごとに能動的に更新を確認）、新しいリマインダーを読み取ったらメモに貼り付けてから完了にします。リマインダーは CloudKit で同期されるため iPhone はすぐにアップロードしますが、ショートカットが保存したファイルは iCloud Drive の都合でアップロードが後回しになることがあります。
* **クラウド上のファイルをオンデマンドで取得**：iPhone から同期されたばかりの `.txt` は、Mac 上ではまだダウンロードされていないプレースホルダのことがあります。`setiopolicy_np` でオンデマンドダウンロードを有効にし、準備ができていないファイルには `brctl download` でダウンロードを促します。読み込みはバックグラウンドスレッドで行うので、あるファイルのダウンロードが遅くても、ほかのメモは待たされません。
* **気づかれない書き込み**：テキストを読み込んだら、アクセシビリティ API でスティッキーズのメニュー「新規メモ」（`⌘N`）を直接実行して内容を書き込みます。スティッキーズのウインドウはアクティブにしません。スティッキーズが起動していない場合はバックグラウンドで静かに起動し、最初の空白メモに直接書き込みます。許可がない場合は `NSPerformService("Make Sticky", …)` に切り替え、できる限りフォーカスを元に戻します。

```text
Sources/main.swift   監視と書き込みのコアロジック（1 ファイル、依存なし）
Info.plist           UI を持たないバックグラウンド App の設定
Icon/                App アイコン（AppIcon.svg が元データ。インストール時に macOS のバージョンに合わせて .icns を選択）
install.sh           ビルド、署名、インストール、自動起動、エンドツーエンドのセルフチェック（繰り返し実行して更新可能）
uninstall.sh         App と自動起動サービスを削除
```
